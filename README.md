Project Title:ShrinkIt – Smart File Compression System

Brief Description:ShrinkIt is a C++-based file compression system that uses the Huffman Coding algorithm to reduce file size. 
It provides file compression and decompression, file information, integrity checking, and duplicate file detection. The project demonstrates the practical 
use of Data Structures, Object-Oriented Programming (OOP), and file handling to make file storage more efficient.

Problem Statement:

Large files require more storage space and can take longer to transfer from one device to another. Managing files efficiently and identifying duplicate or corrupted
files can also be challenging. ShrinkIt aims to solve these problems by providing a file compression system using Huffman Coding, along with file decompression,
file information, integrity checking, and duplicate file detection features.

Objectives:

1-To reduce file size using the Huffman Coding algorithm.


2-To compress and decompress files efficiently.


3-To check file integrity and identify possible file corruption.


4-To detect duplicate files and avoid unnecessary storage.


5-To display file information and compression statistics.


6-To apply Data Structures, Object-Oriented Programming (OOP), and file handling concepts in a practical C++ project.

Project Setup and Installation Instructions:
Prerequisites:
Visual Studio Code (VS Code)
GCC compiler (MinGW on Windows)
C++ source files of the ShrinkIt project

Installation Steps:
1-Install Visual Studio Code on your computer.

2-Install and configure the GCC compiler.

3-Clone or download the ShrinkIt repository from GitHub.

4-Open the project folder in VS Code.

5-Make sure all required source and header files are present in the project folder.

6-Open the terminal in VS Code.

7-Compile the project using the following command (replace filenames if required):
g++ compression.cpp -o ShrinkIt

8-Run the compiled program:

Windows:
.\ShrinkIt.exe

Linux/macOS:
./ShrinkIt

Major Features / Modules:
1-File Compression: Compresses files using the Huffman Coding algorithm to reduce file size.

2-File Decompression: Restores the original file from the compressed file.

3-File Integrity Check: Checks file integrity to help identify possible corruption or unwanted changes.

4-Duplicate File Detection: Helps identify duplicate files to avoid unnecessary storage.

5-File Information: Displays details such as file size and other available file information.

6-Compression Analysis: Shows the original size, compressed size, compression ratio, and space saved.

7-Menu-Driven Interface: Provides a simple menu that allows users to select different operations.
